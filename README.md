# 弓削徹 新刊予約購入キャンペーンLP

11月10日（火）公開予定。公開先は `Booksinfo/yuge` の GitHub Pages を想定しています。

## 公開前の準備

1. キャンペーン事務局が管理する Google アカウントで、下記の内容で特典申込フォームを作ります。
2. 回答用URLを取得し、`campaign.js` の `formUrl` に設定します。編集画面のURLではなく、回答者用のURLを使います。
3. Amazonの商品ページで対象の新刊・予約状況を確認します。LPには資料と同じ商品番号 `4413299140` の通常リンクを設定しています。
4. Booksinfoで `yuge` リポジトリを作成します。LPを事前に登録する場合は、未公開の原稿・画像を保管できる設定で準備します。
5. `index.html` と同じ階層にあるサイトファイルを、リポジトリのルートに配置します。GitHub Pagesの公開は11月10日に行います。`Settings → Pages` で公開元に `main / (root)` を選び、実際に表示された公開URLを確認します。
6. 公開URL、書影の表示、Amazonへの遷移、Googleフォームへの遷移、プライバシーポリシーを確認します。公開URLが想定と異なる場合は、`index.html` のOGPのURLとフォームのポリシーリンクも更新します。

予定のLPは https://booksinfo.github.io/yuge/ です。プライバシーポリシーは `privacy.html` にあります。公開日が変わる場合はポリシーの制定日も確認してください。

[GitHub Pagesの公開元設定](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
